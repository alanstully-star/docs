## Software testing and quality assurance

Software testing is one of Gapvak's two main services, alongside software development.

### Testing tools

| Tool | Purpose |
| --- | --- |
| **Selenium** | Automated testing of web applications |
| **QEngine** | Functional and web application testing |
| **WAPT** | Load and performance testing |

### QA work and clients

- **Oracle Corporation:** Gapvak says it provided engineering and QA services to Oracle.
- **Market2Lead:** Listed as a Gapvak project from 2002 to 2011. Market2Lead was a marketing automation company, later acquired by Oracle.
- **Hushly:** Several Gapvak testers have also held testing roles at Hushly, a B2B marketing software company led by Geoffrey Rego (CEO) and D. Vijaya Kumar Varma (CTO).

### QA roles

Public profiles show these software testing and QA roles at Gapvak:

| Role | Typical responsibilities |
| --- | --- |
| **QA Lead** | Leads testing for product releases and coordinates the QA team |
| **Quality Assurance Engineer** | Plans and runs functional and regression testing |
| **QA and Technical Support Engineer** | Combines testing with customer support |
| **Software Tester** | Gathers requirements, prepares and runs test cases, records results and updates test documents |
| **Software QA Tester** | Runs manual tests and reports defects |
