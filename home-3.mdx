Software teams rely on three closely connected disciplines: **development** builds the product, **testing** checks that it works, and **quality assurance (QA)** makes sure the whole process produces reliable software. This guide explains each career path, the skills it needs and how to get started.

## Testing vs. quality assurance

The two terms are often used interchangeably, but they focus on different things.

|  | Software testing | Quality assurance |
| --- | --- | --- |
| Focus | The product | The process |
| Goal | Find defects | Prevent defects |
| Timing | During and after development | Across the whole lifecycle |
| Typical question | "Does this feature work?" | "Is our way of working producing reliable software?" |

## Software development

Software developers turn requirements into working software. They design solutions, write code, review each other's work and fix issues found in testing or production.

### Common roles

- **Frontend developer**: builds the user interface of web and mobile apps.
- **Backend developer**: builds servers, APIs, databases and business logic.
- **Full-stack developer**: works on both frontend and backend.
- **Mobile developer**: builds apps for Android and iOS.
- **DevOps engineer**: automates building, deploying and running software.
- **Data or machine learning engineer**: builds data pipelines and models.

### Key skills

- At least one programming language, such as Python, JavaScript, Java or C#
- Data structures, algorithms and problem solving
- Version control with Git
- Databases and SQL
- Writing unit tests for your own code
- Teamwork, code reviews and clear communication

### Typical career path

<Steps>
  <Step title="Junior developer">
    Completes well-defined tasks with guidance from senior team members.
  </Step>
  <Step title="Developer">
    Owns features from design to release and works independently.
  </Step>
  <Step title="Senior developer">
    Leads technical decisions, mentors others and reviews designs.
  </Step>
  <Step title="Lead, architect or engineering manager">
    Shapes system architecture or manages people and delivery.
  </Step>
</Steps>

## Software testing

Software testers check that software behaves as expected. They design test cases, run them, report defects and confirm fixes.

### Types of testing

- **Manual testing**: a tester follows test cases and explores the software by hand.
- **Automation testing**: scripts run tests automatically and repeatedly.
- **Functional testing**: checks that features meet their requirements.
- **Regression testing**: checks that new changes did not break existing features.
- **Performance testing**: measures speed, load handling and stability.
- **Security testing**: looks for vulnerabilities.
- **Usability testing**: checks how easy the software is to use.

### Common roles

- **Manual tester**: designs and runs test cases and reports bugs.
- **Automation test engineer**: writes and maintains automated test suites.
- **Performance tester**: plans and runs load and stress tests.
- **Security tester**: performs vulnerability assessments and penetration tests.

### Key skills

- Attention to detail and analytical thinking
- Writing clear test cases and bug reports
- Understanding the software development lifecycle (SDLC) and software testing lifecycle (STLC)
- Basic programming for automation, often in Java, Python or JavaScript
- Familiarity with testing tools

### Popular tools

| Area | Examples |
| --- | --- |
| Web automation | Selenium, Cypress, Playwright |
| Mobile automation | Appium |
| API testing | Postman, REST Assured |
| Performance testing | JMeter, k6 |
| Test and bug management | Jira, TestRail |

## Quality assurance

QA professionals look beyond individual tests. They define standards, review processes and work with the whole team to prevent defects before they happen.

### Common roles

- **QA analyst**: reviews requirements, plans testing and tracks quality metrics.
- **QA engineer**: combines testing with process improvement and automation.
- **SDET (Software Development Engineer in Test)**: builds test frameworks and tooling with strong coding skills.
- **QA lead or QA manager**: sets the quality strategy and leads the QA team.

### Key responsibilities

- Defining quality standards and acceptance criteria
- Creating test strategies and test plans
- Reviewing requirements early to catch gaps
- Tracking metrics such as defect rates and test coverage
- Adding automated tests to continuous integration (CI/CD) pipelines
- Running retrospectives on defects to improve the process

### Typical career path

<Steps>
  <Step title="Junior tester or QA analyst">
    Runs test cases, reports defects and learns the product.
  </Step>
  <Step title="QA engineer or automation engineer">
    Designs test plans and builds automated tests.
  </Step>
  <Step title="Senior QA engineer or SDET">
    Owns test frameworks and the overall test strategy for a product.
  </Step>
  <Step title="QA lead or QA manager">
    Leads the team and sets quality standards across projects.
  </Step>
</Steps>

## Certifications

Certifications are optional but can help you stand out.

<AccordionGroup>
  <Accordion title="Software development" icon="code">
    - Cloud certifications such as AWS, Microsoft Azure or Google Cloud
    - Language or platform certifications, such as Oracle Java

    - ISTQB Certified Tester Foundation Level (CTFL)

  </Accordion>
</AccordionGroup>

## How to get started

<Steps>
  <Step title="Choose a path">
    Decide whether you enjoy building features, finding problems or improving processes. Many people move between these paths during their career.
  </Step>
  <Step title="Learn the fundamentals">
    Learn a programming language, Git and the basics of the software development lifecycle.
  </Step>
  <Step title="Practice on real projects">
    Build small apps, write automated tests for them or contribute to open source projects.
  </Step>
  <Step title="Build a portfolio">
    Share your code, test suites and sample bug reports on GitHub.
  </Step>
  <Step title="Apply for entry-level roles">
    Look for junior developer, junior tester or QA analyst roles and internships.
  </Step>
</Steps>

<Tip>
  Developers who understand testing write better code, and testers who can code write better automation. Skills in both areas make you more valuable on any team.
</Tip>
