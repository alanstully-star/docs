## Run the app

Start the backend and the frontend in two separate terminals.

<Tabs>
  <Tab title="Backend">
    ```bash
    cd [backend folder]
    npm start
    ```

    The API runs at `http://localhost:[BACKEND_PORT]`. [For development, the project may use `npm run dev`.]
  </Tab>

  <Tab title="Frontend">
    ```bash
    cd [frontend folder]
    npm start
    ```

    The app opens at `http://localhost:[FRONTEND_PORT]`. [A Vite project usually uses `npm run dev`.]
  </Tab>
</Tabs>

## Check that it works

<Steps>
  <Step title="Open the app">
    Go to `http://localhost:[FRONTEND_PORT]` in your browser.
  </Step>
  <Step title="Register a test student">
    Follow [Student registration](/student-app/features/student-registration) to add a test student.
  </Step>
  <Step title="Confirm it was saved">
    The student should appear in the student list.
  </Step>
</Steps>

If something does not work, see [Troubleshooting](/student-app/troubleshooting/troubleshooting).
