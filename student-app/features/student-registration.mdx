Student registration adds a new student record to the system. Each student is saved with their personal details and gets a unique ID.

<Note>
  Field names, validation rules and screen labels below are typical examples. Replace them with the ones the app actually uses.
</Note>

## Before you start

- You need an account with permission to add students. [Confirm roles, if the app has login.]
- Have the student's details ready.

## Register a student

<Steps>
  <Step title="Open the registration form">
    Select **Register Student** (or **Add Student**) from the main menu. [Confirm the menu label.]
  </Step>
  <Step title="Enter the student's details">
    Fill in the fields in the table below. Fields marked as required must be completed.
  </Step>
  <Step title="Submit the form">
    Select **Register** (or **Save**). The app validates the form and saves the record.
  </Step>
  <Step title="Check the confirmation">
    A confirmation message appears and the new student shows up in the student list.
  </Step>
</Steps>

## Validation and errors

| Problem | What it means |
| --- | --- |
| A required field is empty | Fill in the field and submit again |
| Invalid email | Check the email format |
| Email already registered | A student with this email already exists. Open their record instead of registering again |

## Behind the scenes

Registration sends a request to the backend API. [Confirm the endpoint and fields.]

```http
POST /api/students
Content-Type: application/json

{
  "name": "[Student name]",
  "email": "[student@example.com]",
  "dateOfBirth": "[YYYY-MM-DD]"
}
```
