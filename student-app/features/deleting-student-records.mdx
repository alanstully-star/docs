Deleting removes a student's record from the system. Use it for records that were created by mistake or are no longer needed.

## Delete a student record

<Steps>
  <Step title="Find the student">
    Open the [student list](/student-app/features/student-records) and search for the student.
  </Step>
  <Step title="Select Delete">
    Select **Delete** next to the student, or open the record and select **Delete**.
  </Step>
  <Step title="Confirm the deletion">
    A confirmation box asks you to confirm. Select **Confirm** (or **Yes, delete**) to continue, or **Cancel** to keep the record.
  </Step>
  <Step title="Check the result">
    A message confirms the deletion and the student no longer appears in the list.
  </Step>
</Steps>

## Before you delete

- Check that you have the right student. Use the student ID if two students have similar names.
- Make sure you have permission to delete records. [Confirm roles.]
- Export or back up any information you still need. [Confirm whether the app has an export feature.]

## Behind the scenes

Deleting sends a request to the backend API. [Confirm the endpoint.]

```http
DELETE /api/students/:id
```
